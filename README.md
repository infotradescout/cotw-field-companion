# COTW Field Companion

Unofficial, local-first companion for theHunter: Call of the Wild. Automatic save-derived harvest and zone tracking with an offline animal reference. Public web preview, career statistics and share studio are being added to this same application.

## Run locally
Node.js 22.13 or newer is required. Run `node launcher.mjs --open`. The observer reads saves; it never writes to them. This is an early preview, not an approved or official game extension. Keep a normal game backup.

## Privacy
No user saves, journals, account IDs or native screenshots are included. The local app writes only its own journal.
